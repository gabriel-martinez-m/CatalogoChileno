# Base de Microservicios

Estructura inicial para los microservicios: 
**autenticacion**, 
**carrito**, 
**catalogo**, 
**ordenes** y 
**usuarios**.

## Configuración Base

* **Spring Boot:** 4.1.2
* **Java:** 21
* **Gestor de dependencias:** Maven
* **Empaquetado:** JAR
* **Configuración:** `application.properties`

## Dependencias Incluidas

* Spring Web
* Spring Data JPA
* Validation
* MySQL Driver
* Lombok
* H2 Database
